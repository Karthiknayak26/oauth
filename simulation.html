OAuth2 Flow Steps:
User clicks "Login with Provider"
Client redirects to Authorization Server
User logs in & grants permission on Auth Server
Auth Server redirects back to Client with Auth Code
Client exchanges Auth Code for Access Token (server-to-server)
Client uses Access Token to request data from Resource Server
Resource Server validates token & returns data
User logged in & data displayed!

🔀 Understanding the OAuth2 Flow

Authorization Code: Short-lived, single-use code sent from Auth Server to Client via user's browser.

Access Token: Secret token Client uses to access Resource Server on behalf of the user. Usually has an expiry.

Redirect URI: Pre-registered location on Client where Auth Server sends the Auth Code.
