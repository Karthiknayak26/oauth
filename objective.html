Experiment Objectives

This page details the specific learning objectives and goals of the OAuth2 experiment.

  • Understand the four roles in the OAuth2 framework: Client, Resource Owner, Authorization Server, and Resource Server.
  • Gain hands-on experience implementing the OAuth2 "Authorization Code" grant type.
  • Learn how a client application securely obtains an authorization code and exchanges it for an access token.
  • Demonstrate how to use a received access token to make authenticated requests to a protected Resource Server.
  • Understand the importance of scopes, client secrets, and registered redirect URIs in securing the authorization flow.
