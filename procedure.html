Procedure

Step-by-Step Guide

This section outlines the detailed steps to conduct the experiment simulating the OAuth2 Authorization Code Flow.

  1. Set up the Environment:
    • Create three projects: Client Application, Authorization Server, and Resource Server.
    • Authorization and Resource Servers can be combined with distinct endpoints.
  2. Register the Client Application:
    • Configure client credentials on the Authorization Server.
    • Provide Client ID, Client Secret, and Redirect URI (e.g., http://localhost:3000/callback).
  3. Implement the Authorization Endpoint:
    • Create `/authorize` endpoint accepting client_id, response_type=code, and redirect_uri.
    • Display login and consent screens, then redirect with an Authorization Code.
  4. Implement the Token Endpoint:
    • Create secure `/token` endpoint to exchange code for Access Token.
    • Validate client_id, client_secret, and authorization_code.
  5. Implement the Resource Server Endpoint:
    • Create `/api/userinfo` endpoint validating Authorization: Bearer <access_token> header.
    • Return mock protected user data.
  6. Implement the Client-Side Flow:
    • Create a login button linking to `/authorize` with proper parameters.
    • Handle `/callback` to exchange code for Access Token.
    • Use Access Token to fetch data from `/api/userinfo`.
